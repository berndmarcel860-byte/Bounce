# Bounce

## Bounce Bolt

This repository now contains **Bounce Bolt**, a one-touch endless neon arcade prototype optimized for mobile browsers and easy wrapping for Android/iOS webview builds.

### Run locally

```bash
cd /home/runner/work/Bounce/Bounce
python -m http.server 8080
```

Open `http://localhost:8080` on desktop/mobile.

### Included systems

- One-touch gravity bounce orb gameplay with instant retry
- Endless procedural obstacle generation with weighted difficulty phases
- Obstacle set: wall gaps, moving barriers, rotating lasers, pulsing blocks, gravity/speed zones, orbitals, crushers, teleports, zigzags, moving spikes, trap combos
- Score + combo + near-miss + perfect pass feedback
- Coins/XP progression and cosmetic unlock categories
- Daily rewards, daily missions, weekly challenge target, achievement/session stats
- Local daily/weekly/all-time/friends leaderboard panels
- Minimal HUD and neon animated UI/theme system
